## 启动与操作

```bash
cd /home/smgbro/mujoconew/GITHUB
bash scripts/169_launch_random_tabletop.sh
```

需要共享盘和图形桌面。默认进入“随机桌面 · 已知初始位置”，旧桌面视觉模式和原标准场景仍可切换。

1. 设置“桌面种子”。相同种子重复生成相同初始布局；刷新图标切换下一种子。
2. 干扰物数量可选随机，或手动设为 0–4。数量不包含杯子。
3. 选择目标跟随种子随机生成，或切换“手动坐标”，填写世界坐标 X、Y、Z，单位为毫米。
4. 选择第一或第二视频抓法，输入“把杯子搬到目标位置”，点击执行。“抓起杯子”只执行到抬杯阶段。
5. 参数页显示实际初始杯位置、目标、物品列表和模型路径；主画面显示连续物理仿真、接触力、杯底高度、目标距离和穿透值。运行时锁住参数编辑，停止按钮仍可用。

目标是**杯子模型原点**的位置，不是杯底位置；搬运成功后保持抓握，没有新增松手放置技能。参数修改在下一次执行时生效。

## 本轮随机范围

| 项目 | 范围 |
| --- | --- |
| 杯子 | 训练使用的 YCB 025_mug，缩放 0.8；杯型、动力学与朝向不变 |
| 杯子初始 X / Y | -45 至 45 mm / -30 至 30 mm |
| 目标 X / Y / Z | -40 至 40 mm / -80 至 0 mm / 140 至 190 mm |
| 干扰物 | 0–4 件；香蕉、糖盒、芥末瓶、罐头中随机选择 |
| 干扰物布局 | 桌面左右两侧随机位置、偏航角；物体中心间距至少 170 mm |
| 桌面 | 三种外观，尺寸及物理台面保持一致 |

这是 Adroit 当前安装方式下的受限工作区，不是整张桌面任意位置可达。干扰物布置在中央操作通道外；本轮没有新增绕障规划或从拥挤物堆中取杯。所有物体均自由运动，执行时没有写入杯子位姿、吸附约束或额外抬杯力。

## 控制方法

- 抓取前从仿真获取一次已知杯位姿。实时杯位姿只用于阶段条件、安全检查、评价和显示，不输入电机动作计算。
- 第一视频保留原手指时序，抬杯后用五次平滑插值将搬运终点变换到用户目标。
- 第二视频在抓稳后重建手腕伺服的平衡指令，避免冻结闭合末帧的动态跟踪偏差；再根据拇指、食指、中指的正运动学位移推算杯子运动，进行有界搬运纠偏。
- 两者继续调用已有结构化残差 checkpoint。它是参考条件控制，不是新训练的端到端视觉策略。

## 验收方法

开发种子 10–21，共 24 次两视频回放，用于修正控制。之后冻结源码、模型哈希、分布和种子，再运行独立种子 1001–1040，每种抓法 40 次，共 80 次。零步准入失败、碰撞停止和到位失败均计入分母，不重抽成功种子。

完整成功需要接近、持续三指对握、抬杯、到位保持全部通过，同时满足原门槛：手部相关穿透不超过 1 mm、关节越限不超过 0.02 rad、无手与非目标物碰撞、杯底高于 50 mm、最终目标误差不超过 20 mm。不能用抓起率替代搬运完整成功率。

两个视频共享同一组 40 个布局，因此报告同时给出每视频成功率与“两种抓法均成功”的布局级 Wilson 95% 区间，不把 80 次回放冒充 80 个独立布局。
