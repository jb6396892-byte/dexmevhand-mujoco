初始区域从 9 × 6 cm 扩大为 **15 × 15 cm，面积约 4.17 倍**；目标包围盒体积约 5.06 倍。杯子初始高度仍由桌面支撑决定，目标 Z 是杯模型原点的高度。仍保留同一个杯子、固定朝向、0–4 件随机干扰物及中央无障碍操作通道。

## Qt 操作

```bash
cd /home/smgbro/mujoconew/GITHUB
bash scripts/169_launch_random_tabletop.sh
```

1. 在侧栏“初始位置”页签，选择“手动坐标”，填写初始 X/Y；也可以保留“跟随种子”。
2. 切换“目标位置”页签，选择手动或随机目标，再设置 X/Y/Z。
3. 选择抓法和干扰物数量，输入“把杯子搬到目标位置”，点击执行。
4. 初始位置和目标互不覆盖；相同种子与相同参数可复现。执行期间不能修改这些参数，下一次运行时才应用新设置。

两个已执行的界面案例：

- 第一视频：初始 `(-70, 60)` mm，目标 `(70, -85, 150)` mm，四件干扰物。
- 第二视频：初始 `(70, -60)` mm，目标 `(-70, 85, 195)` mm，两件干扰物。

旧版仍可运行，不需要切换 Git 分支：

```bash

```

## 修正与验证

起初尝试目标高度 110–220 mm。开发回放发现第一视频低目标使竖直关节规划越过下限，第二视频高目标在纠偏后触碰上限；失败日志保留，没有删除这些案例或扩大关节限位。

最终采用 140–200 mm；固定安装偏置按视频调整以分配关节行程余量，变换初始关节坐标时保持初始手部世界姿态不变。偏置不随杯位置或种子变化，执行中不瞬移机械手或杯子。

开发种子 30–41，两视频共 24 次；初始四角 × 目标上下端 × 两视频共 16 次边界回归。之后冻结模型、控制代码和新分布，独立种子 2001–2040，两视频共 80 次。新独立结果不能用 v5 的 80/80 替代。

全部沿用原物理标准：持续三指对握、杯底抬高至少 50 mm、目标误差不超过 20 mm、穿透不超过 1 mm、无手与干扰物碰撞、关节越限不超过 0.02 rad。
