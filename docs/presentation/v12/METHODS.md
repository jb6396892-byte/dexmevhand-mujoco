# v12：阶段对齐与参考条件接触控制

日期：2026-10-02。目的不是宣称复现外部论文，而是在现有 DexMV/MuJoCo 上做小规模可检查的改进。原 v9/v10/v11 数据、策略及碰撞模型保持不变。

## 1. 两级验收，避免更换标准后混淆结论

- **任务级**：稳定抬杯，目标误差不超过 30 mm，末段至少三指（含拇指）各有至少 80% 承力接触；拇指必须达标。
- **严格级**：保留 v10/v11 原完整门槛，含目标误差 20 mm、四指接触及各指尖参考误差。
- 两级都不允许通过放宽碰撞实现成功：手与场景峰值穿透仍为 1 mm，初态 0.5 mm，承力间隙 0.5 mm，末段滑移 5 mm，关节超限 0.02 rad，动作饱和比例低于 1%。
- 0.75 mm 是此前的额外安全余量偏好，不是本轮训练前必须实现的全部工况硬门槛。
- 杯子的质量、摩擦、碰撞网格、求解参数不修改；执行中仅 `env.step(action)`，没有物体辅助力或逐帧杯子位姿写入。

## 2. 单变量阶段采样对照

保留 v11 的 35 条专家示范、原参考动作、84 维状态特征、64×64 网络、随机种子、学习率、150 轮训练和残差限幅。

唯一干预是以仿真相同的非线性 `source_clock` 将控制时间映射回源视频帧，再在准备、接近、闭合、抬杯、搬运五阶段分配 15%、15%、20%、30%、20% 的采样概率。两视频各占总权重的一半，每视频内各轨迹等权。

```python
phase = aligned_phase_indices(length, geometry, time_scale)
weights = aligned_phase_weights(length, masses, geometry, time_scale)
```

训练误差仅用于监控，不作为抓取验收。第一组完整闭环结果与旧版本对照，不能以“修好了采样实现”代替“策略改善”。

## 3. 参考条件与接触感知的组合试验

第二组不是单变量消融，包含以下相互配合的改动；即使改善也不能单独归因于接触特征。

1. 从复位时实际可观测的杯子位置、朝向和已知任务目标调整名义手部参考动作。只改变期望手部动作，不改变物体状态。不使用该工况优化后的专家动作作为在线输入。
2. 在原 84 维特征上增加期望与实际手关节误差 30 维、参考杯子位置误差 3 维、目标位置误差 3 维、五指接触力与接触距离各 5 维，共 130 维。
3. 接触从 MuJoCo 实际手杯碰撞对提取。没有接触时距离特征使用明确的哨兵值，不能解释为精确最近表面间隙。
4. 在完整专家动作物理重放中采集这些状态，避免从静态 qpos 重新计算接触力造成训练与执行不一致。要求重放观测误差低于 1e-8。
5. 学习有界残差，保持归一化动作约定：

```python
action = adapted_reference[step] + np.clip(residual, -limits, limits)
observation, reward, done, info = env.step(action)
```

## 5. 冻结及独立评估

在接触特征组合方案出现开发退化后，且尚未执行任何新留出测试时，增加了预先限定的接触卸载对照，见 `configs/v12-contact-guard-amendment.json`。以稳定的 84 维阶段策略为基础，根据实际手杯碰撞法向和接触点雅可比，将超过 0.7 mm 的穿透转成小幅手指关节退让。只试 0.15、0.30、0.60 三个增益，关节修正不超过 0.025 rad，经过低通滤波，不增加闭合力、不改变根部动作。这是几何接触反馈，不是新训练的网络，也不是保证约束绝不违反的安全投影器。

开发集仅使用 v11 的 35 个已准入开发工况。预先指定随机种子生成每视频 8 个组合扰动，杯子 XY 范围 ±4 mm、目标 XY 范围 ±18 mm、朝向范围 ±6°。它们是已知两段视频的合成测试，不是新视频或实物泛化。

候选先按两视频等权任务级通过率、严格通过率、目标误差排序。提交冻结回执后才运行独立测试，旧残差、两组新 BC、开发选中的卸载增益及原 v11 固定时间窗 BC 在同一组工况比较。额外保留 v11 基线是为了直接检验阶段采样这一项，不把与旧 v10 的差异都归因于采样。测试后不调整已冻结策略。

## 6. 残差 DAPG 接口

通过现有 MJRL `DAPG.train_from_paths` 接入完整物理采样。观测为选中策略对应的 84 或 130 维，动作密度使用网络采样的**未裁剪残差**；执行动作则为限幅残差加参考动作，由原环境只缩放一次。

使用两视频各自的初态、控制时钟和完整时长。先逐帧比较确定性采样器与 BC 评估的观测/动作是否一致，再做 20 次、每次两条完整轨迹的接口短训。MuJoCo 和旧 MJRL 自然梯度策略更新在 CPU，BC 和价值网络训练使用 GPU；不宣称全 GPU 物理训练。

若选中带几何卸载的策略，DAPG 采样器保留同一反馈层，示范的潜在残差标签需要减去专家状态下的卸载修正。本轮在两条名义专家完整重放中生成该标签，不能直接把原动作当作残差喂给 DAPG。

短训不替换冻结 BC，不重复使用已看过的留出集验证短训策略。采样可运行、参数能更新、物理抓取成功、独立工况有效，分别报告。
