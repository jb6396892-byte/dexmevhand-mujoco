# v14：接触预测修正与长训练准入

本轮从 v13 的最佳开发候选出发，处理“轨迹误差下降、接触穿透却上升”的矛盾。物理门槛仍使用 v12 的任务级标准，原严格抓法标准另外报告。没有改变杯子的质量、摩擦、碰撞模型或穿透验收上限。

## 查询的开源依据

| 来源 | 本轮采用的思路 | 边界 |
|---|---|---|
| [MuJoCo MPC / Predictive Sampling](https://github.com/google-deepmind/mujoco_mpc) | 在副本动力学中比较有限动作候选，使用未来参考动作预测 | 未迁移现代 MuJoCo/Python 环境；这里是兼容旧栈的小型实现，不是完整 MJPC 复现 |
| [MJPC Python 示例](https://github.com/google-deepmind/mujoco_mpc/blob/main/python/mujoco_mpc/demos/predictive_sampling/predictive_sampling.py) | 控制预测应沿时序动作推进，而非一直保持当前控制 | 不将参考物体位姿写入实际执行状态 |
| [预测式安全过滤论文](https://arxiv.org/abs/1812.05506) | 把学习策略与动作约束检查分开 | 本轮没有不变集或不确定性界，不能声称形式化安全保证 |
| [DexMachina 奖励实现](https://github.com/MandiZhao/dexmachina/blob/main/dexmachina/envs/rewards.py) | 接触、姿态跟踪、力惩罚是不同目标，不能只看 BC 损失 | 不引入其虚拟物体辅助控制器，不宣称完整复现 |
| [DexTrack](https://github.com/Meowuu7/DexTrack) | 参考条件轨迹跟踪与分层优化的方向 | 官方仓库说明部分 specialist/generalist 迭代和同伦优化组件未公开，不能假定可以直接运行全流程 |

## 机制

1. 神经网络输出有界残差，与既有参考动作相加。
2. 新建独立 `MjSim` 数据，复制当前真实状态和求解器 warm start，仅用于预测。
3. 比较未修改动作、接触法向微调以及有界关节候选。后续版本沿未来参考动作预测，不读取未来真实物体状态。
4. 代价考虑穿透超额、支撑接触丢失、对杯子预测轨迹的扰动及修改幅度。
5. 只把选出的手部归一化动作送到真实 `env.step`。真实环境不会被恢复为预测状态，也不给物体施加辅助力。

副本预测的一步状态与随后真实执行对比，要求最大误差不超过 `1e-7`。物理执行和副本均只做一次动作归一化缩放。

## 预先规定的长训检查

- 两个视频各自开发工况任务级通过率至少 80%。
- 冻结后，每视频八个新组合扰动中任务级至少 6/8、稳定抬杯至少 7/8。
- 两个名义工况标准步长和半步长任务检查均通过。
- 残差 DAPG 短训完成 20 次有限、非零更新，训练后两名义工况任务级通过。
- 新测试不用于反复调参；未通过就记录阻碍，不把开发集结果当泛化结果。

这些是本轮“可以开始受控长训练”的工程准入，不是部署成功率或忠实复现全部视频抓法的结论。达到后仍先汇报，不自动运行 2000 次训练。

## 已完成的开发对照

| 版本 | 开发小试任务级 | 完整开发任务级 | 完整开发严格级 |
|---|---|---|---|
| v13 最佳共享残差 BC | 作为基线 | 29/35 | 27/35 |
| v14：30 ms、固定未来动作、法向修正 | 2/4 | 未运行 | 未运行 |
| v14b：150 ms、未来参考、法向修正 | 2/4 | 未运行 | 未运行 |
| v14c：150 ms、未来参考、法向及坐标候选 | 4/4 | 35/35 | 33/35 |

v14c 第一视频任务级 18/18、严格级 16/18，预测修正没有改变其动作；第二视频任务级及严格级均为 17/17。两视频等权平均目标误差 5.74 mm，与原基线几乎持平，主要收益是接触峰值下降，不是到位误差全面改善。

修正不是简单增大闭合力度：候选同时包含正负方向的拇指、中指和手腕微调，并在真实动力学预测中比较。关节偏置上限 0.06 rad，手腕平移控制目标偏置上限 1 mm，均通过执行器动作实现，不直接平移物体。

开发集最紧的通过场景峰值约 0.995 mm，距离 1 mm 验收上限只有约 0.005 mm，不能据此声称鲁棒安全保证。新测试与 DAPG 短训仍需独立验收。
