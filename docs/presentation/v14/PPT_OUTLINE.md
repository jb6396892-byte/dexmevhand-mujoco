# 答辩提纲：从轨迹模仿到接触可执行的学习控制

## 第 1 页：问题和边界

- 输入来自两段 DexYCB 真实抓杯记录，复用已转换的 MANO、杯子位姿和参考轨迹。
- 人手到 Adroit 的结构差异使“轨迹拟合更准”不等于“接触更稳定”。
- 目前验证对象是已知两类抓法及合成场景扰动，不是新视频自动理解，也不是实物部署。
- 共享盘当前未连接，本轮不声称重新完成原始视频和 MANO 核验。

## 第 2 页：为什么没有继续堆闭合力或网络数量

引用 v13 等预算开发对照：共享、分视频、分阶段任务级分别为 25/35、24/35、22/35；加入纠偏数据后的 24/35 不及只用原数据再训的 29/35。

讲解重点：专家接管成功、模仿损失下降和学生闭环成功是不同指标；必须在自由杯子动力学中检查碰撞峰值。

## 第 3 页：当前控制架构

```text
真实视频标签 -> 坐标/重定向 -> 经过物理验收的参考动作
                                      |
实时状态 + 视频身份 + 精确阶段 -> 共享残差网络
                                      |
                         参考动作 + 有界残差提议
                                      |
               独立 MuJoCo 副本预测未来 150 ms
                    比较法向与有界坐标候选
                                      |
                     选中手部动作 -> env.step
                                      |
                      自由杯子物理状态反馈
```

这不是专家混合语言模型。视频身份由任务指定，尚未训练高层语言规划器。绿色透明杯子只是无碰撞目标标记。

## 第 4 页：关键实现和创新边界

对应代码：`src/fromrealhand/predictive_contact.py`。

```python
future = action + reference[future_step] - reference[current_step]
branch.ctrl[:] = act_mid + np.clip(future, -1., 1.) * act_rng
offset, prediction = min(candidates, key=cost)
executed_action = action + conversion * offset
```

上面是便于讲解的简化伪代码，省略分支初始化、索引边界和循环，实际实现见源码。预测状态只写到独立 `MjSim.data`；实际环境只接收动作。副本一步预测和下一真实物理状态逐步核对，开发最大误差约 `5.6e-10`，小于 `1e-7` 审计上限。

代价分开衡量穿透、承力接触丢失、杯子轨迹扰动和动作修正幅度。借鉴 MuJoCo MPC 的预测采样和 DexMachina 的接触目标分解，是面向旧 DexMV 栈的工程组合与验证方法，不能包装成新理论、完整论文复现或形式化安全过滤器。

## 第 5 页：开发实验和负结果

- 30 ms 固定动作预测：小试 2/4。
- 150 ms 未来参考但仅法向修正：小试仍为 2/4。
- 加入正负有界坐标候选：小试 4/4，完整开发任务级 35/35、严格级 33/35。
- 第一视频任务级 18/18、严格级 16/18；第二视频两者均 17/17。
- 目标平均误差约 5.74 mm，与基线接近。主要改善是接触验收，不是所有指标都变好。

放两张同一工况同一时刻的前后图，旁边放峰值表。截图不能分辨亚毫米穿透，定量结论来自接触数据，不来自视觉观感。

## 第 6 页：冻结后测试

先提交策略、配置、代码哈希，再生成每视频 8 个新的组合扰动；相同场景配对比较无过滤器基线和带过滤器候选。开发数据、独立测试和 DAPG 短训结果分别报告。

任务级由 11/16 到 15/16，严格级由 6/16 到 7/16，稳定抬杯均为 16/16，目标误差由 9.16 mm 到 8.86 mm。引用 `evidence/heldout.json`，同时展示失败类型；样本量小，不应宣称统计显著或未见视频泛化。

## 第 7 页：接触感知残差 DAPG 接口

对应 `scripts/87_train_v14_dapg.py` 与 `src/fromrealhand/contact_training.py`：

```python
path['actions'] = raw_sampled_residual
path['rewards'] = native_rewards - measured_contact_costs
stats, update = bounded_update(agent, paths, max_kl=0.002)
```

- 概率密度使用未裁剪残差，环境使用参考加有界残差后的实际动作，不能混用。
- 接触代价来自动作后的真实物理数据，不是预测副本的代价。
- 旧 DAPG 内部更新尺度被硬编码；在本项目增加实测 KL 回溯检查，不修改外部学习库。
- 20 次短训只证明可采样、可更新及名义闭环不崩溃，不证明长期收益。最终数字引用 `evidence/dapg-smoke.json`。
- 已完成 20 次非零更新，最大 KL 为 0.000636；40 条探索轨迹任务级 39/40，训练后两个名义工况任务及严格均通过，目标误差 0.60/4.63 mm。

## 第 8 页：结论和仍需解决的问题

- `evidence/readiness.json` 的 27 项检查均通过，已经达到受控长训最低条件，但本轮没有启动长训。
- 第一视频仍有严格抓法误差；小指并非持续承力，视频也没有真实接触力标签。
- 部分开发工况接近 1 mm 穿透上限，半步长会改变轨迹，不能宣称接触安全已有充分余量。
- 预测仿真增加 CPU 开销，不能宣称实时 100 Hz 或 GPU 并行物理训练。
- 下一步先做受控分段长训、保存并评估中间策略，再扩展独立真实视频；不直接跳到实物部署。
