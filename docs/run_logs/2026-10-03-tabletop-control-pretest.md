# 视觉控制和 Qt：测试前记录

2026-10-03，按用户“做到测试前”要求，不启动测试与训练。

## 工作过程

1. 阅读旧 Qt、语言门控、技能执行器、参考分段、YCBRelocate 和 MuJoCo 本地绑定。发现旧参考后端要求逐步状态与原场景一致，不能直接用于新桌面。
2. 检索 MimicGen 官方论文/代码及 robosuite 控制器说明，采用有限物体相对轨迹变换。不下载大库，不升级旧依赖。
3. 新增独立控制场景工厂，解除感知场景的手部停放约束，按名称复制参考物理参数，初始化后只使用电机动作步进。
4. 新增视觉姿态校验、参考手腕变换、有界本体反馈和安全停止。没有把模拟物体 qpos 当作观测。
5. 发现原静态 ICP 的桌面高度约束不适合抬杯。新增上一视觉位姿初始化的离桌跟踪候选；保留质量和跳变拒绝，等待遮挡及漂移测试。
6. 新增驻留视觉子进程和暂停式采样通信，阻断帧错配、过期及推理超时；避免 GUI 进程混用 PyTorch 与旧 OpenGL 库。
7. 通过子类扩展 Qt，新启动入口默认锁定桌面执行。旧 Qt 和原感知文件未修改。
8. 准备 8 项纯函数测试，但未运行。AST/JSON/bash 语法检查和差异检查已执行。
9. 使用既有图片打开 Qt 排版视图并保存一张截图。没有模型推理、没有 MuJoCo 初始化和步进，不将该截图作为功能验收。
