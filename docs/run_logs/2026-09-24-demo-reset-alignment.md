- 强制逐帧加载示范的 MuJoCo 状态时，292 帧中有 157 帧检测到手杯接触，杯子最高为 `0.2623 m`。这只能证明位姿序列显示抓取，不能证明动作可由动力学重现。
- 示范观测前 30 维关节状态属于当前帧，后 9 维空间特征**精确等于上一帧**（逐元素最大误差 0）。第 0 帧保存的空间观测与该帧真实状态最大差 `0.5078 m`。原因是 `relocation_demo.py` 在调用 `sim.forward()` 前采集了观测和奖励。
- 从示范首帧状态出发，按保存的 292 个动作正常调用 `env.step()`：接触 0 帧，杯子最高仅 `0.0809 m`，随后偏离桌面；手部 qpos 与示范下一帧的误差中位数约 `3.32`。现有动作序列不是可靠的可执行动力学示范。动作饱和比例约 `20.76%`。

结论：不能直接扩大当前 DAPG 训练。先统一示范和环境的手、杯、目标坐标及初始高度；修正示范采集时的 `sim.forward()` 顺序并重新生成数据；再从示范首帧重放动作，要求动力学中出现稳定接触和抬升，最后才恢复训练。不要只修一帧观测或平移杯子坐标后就宣称问题解决。
