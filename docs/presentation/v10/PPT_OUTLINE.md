## 可主张的工程贡献

1. 把真实视频位姿、关节重定向、自由物体动力学和抓法验收接成可复查流水线。
2. 同时约束抓取成功与人手抓法，而不是只优化杯子高度。
3. 两视频保持各自时钟和参考动作，比较直接学习与残差学习的实际闭环能力。
4. 预注册工况、冻结策略、配对基线、保存失败记录，避免仅展示成功动画。

这些是本项目已经实施的工程工作，不是经过文献查新证明的首创算法。讲解时不要把现有 BC、残差控制、Powell 优化称为新发明。
