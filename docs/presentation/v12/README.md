# v12：从固定参考到接触感知闭环

本轮按“阶段采样修正、参考与接触特征、小规模对照、新留出评估、残差 DAPG 接口”推进，保留原有版本。

## 本轮结论

- 阶段采样已接入 150 轮 BC，保持原示范、网络和训练种子不变。新留出严格通过 6/16，原 v11 为 5/16；目标误差从 17.84 降至 12.77 mm，但任务级从 11/16 降至 10/16，不能宣称整体优势。
- 参考条件与接触特征组合方案在第二视频新留出中 0/8 抬杯，未采用；接触法向卸载也未提高通过率。这两项是有记录的负结果，不是已经解决的问题。
- 残差 DAPG 完成 20 次非零更新、57,340 个仿真控制步。两条名义工况严格通过，目标误差 1.19 / 3.99 mm；第二视频峰值穿透 0.970 mm，距 1 mm 上限余量仍小。
- 89 项测试通过；冻结哈希、80 次留出结果、35 条专家重放及 24 张截图已核验。长训练未启动，DAPG 新策略尚未独立留出评估。

## 答辩叙事

1. **问题**：分别优化的专家动作能抓杯，不代表共享策略学会；指尖接近也不等于承力接触。
2. **单变量检查**：原固定时间窗与视频阶段错位，先修采样，不把工程修正直接称作算法收益。
3. **方法**：参考动作根据初态与目标适配，再用参考误差和仿真接触反馈预测有界残差。
4. **证据**：同时展示开发集和冻结后测试，任务完成与抓法忠实度分开统计。
5. **边界**：借鉴现有论文，不宣称重新发明残差、接触映射或 DAgger；只有两段源视频，尚非实物泛化。
