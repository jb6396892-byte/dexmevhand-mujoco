# v10 方法、代码摘录与答辩口径

## 1. 数据和控制层次

```text
DexYCB 两段真实采集序列的缓存位姿
  -> MANO/手部重定向与统一坐标
  -> 每种抓法独立的名义专家动作轨迹
  -> 开发场景的平滑腕部修正 + 自由物体动力学 shooting
  -> 原物理门槛 + 精确重放 + 半步长复核
  -> 27 条合格示范 / 38,622 帧
  -> 抓法条件化直接 BC / 抓法条件化残差 BC
  -> 开发集选检查点 -> 冻结哈希 -> 一次配对留出测试
```

这不是高层语言规划器。抓法 ID 目前由程序选择，不由语言模型推断；网络接收仿真状态，不直接接收 RGB。两段真实视频加上合成工况仍然只有两种真实示范来源。

## 2. 从 v9 到新开发工况

首先将杯子位置、目标、朝向的变更转成平滑的腕部参考变化。起始手状态保持不变，位置和朝向修正通过控制动作逐渐施加。

如果完整物理门槛仍未通过，优化 30 维关节等效偏置，经五次平滑包络作用于动作，直接在 MuJoCo 的自由杯子动力学内评估。目标函数兼顾无名指间隙、其余承力指接触、指尖误差、搬运目标误差、杯子速度、穿透与饱和。不是增大单个手指闭合力度，也没有调整杯子质量或摩擦来凑成功。

实现：`scripts/66_develop_second_video.py`、`scripts/v10_common.py` 和已有 `scripts/64_optimize_dynamic_contact.py`。

```python
report, demo = run_case(video, source, actions)
passed = (report['surface_physics_passed']
          and report['fidelity_passed']
          and report['final_distance_m'] <= .02)
```

优化目标只帮助搜索，完整门槛才决定录取；失败候选保留在各工况的 admission 和 repair/progress 中。

## 3. 双视频策略

直接 BC：`a = policy(state, phase, video_id)`。

残差 BC：`a = reference[video_id][step] + policy(state, phase, video_id)`。

残差是归一化动作空间中的修正。MuJoCo 环境负责一次裁剪和执行器缩放，不在外部再次缩放。固定参考本身有很强的抓取能力，所以必须同时报告固定动作基线，不能把参考轨迹的能力算成网络贡献。

`src/fromrealhand/multivideo.py` 的关键执行逻辑：

```python
action = checkpoint['policy'].model(features)
if checkpoint['method'] == 'residual_bc':
    action = action + reference[step]
env.step(action)
```

以上为便于幻灯片阅读的摘录；完整代码包含输入维度、有限值、抓法时钟和参考长度校验。每段视频分别保持初态、参考动作和 1417/1450 步时长。

## 4. 训练与测试隔离

- 开发集用于重新优化示范和选择 50/150/300 epoch 检查点。
- 训练按两视频各占一半的权重采样，各视频内部每条轨迹等权。
- 开发闭环评估先比较各视频平均完整通过率，再比较平均目标距离，最后取更早的检查点。
- 候选策略文件、数据集和工况协议均保存 SHA-256；提交候选清单后才运行留出集。
- 留出集每视频 10 项，杯子偏移 3.5 mm、目标偏移 17 mm、朝向正负 4.5 度。不使用留出结果调整策略。
- 这属于新的合成工况，不是独立新视频、不同杯子或实机泛化。第一视频旧开发集含更大朝向范围，因此其留出朝向属于插值测试。

## 5. 验收和限制

完整成功不只看抬杯：还要求目标距离不超过 20 mm、手-场景穿透不超过 1 mm、初始穿透不超过 0.5 mm、承力间隙不超过 0.5 mm、末段滑移不超过 5 mm、动作饱和低于 1%，并满足原有稳定抬杯和关节限位要求。

抓法要求拇指、食指和至少四指末段持续承力，接触比例至少 0.8；末段平均指尖误差低于 15 mm，单指低于 25 mm，整段均值低于 20 mm。详细逻辑沿用 `33_optimize_surface_grasp.surface_gate` 与 `30_validate_video_faithful`，没有为本轮放宽。

阶段窗按源帧预定义：接近 0–29、闭合 30–39、抬杯 40–54、搬运保持 55 以后。它们是分析用时钟窗，不是人工逐帧动作标签。开发集额外记录相对专家杯轨迹首次偏离 10 mm 的控制步。

v9 无名指在抬起后才持续承力；小指不持续承力。真实视频没有接触力标签，初始手形误差仍存在。通过仿真门槛不等于逐帧忠实复现，更不等于通过实机安全验证。
