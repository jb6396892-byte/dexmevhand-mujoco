## 调试过程

- 尺寸目录在所有对象重叠时触发 contact buffer full，修正为分离的只读尺寸采集场景。
- 连接杆/手掌干涉：最大穿透约 0.02995 m，结构调整后种子 0 稳定场景降为 0.000635 m。
- `f1-dev-a` 的 3 个布局、9 个到位和6个近限位点均通过，但默认离屏 GL 初始化失败，首轮不能算完整验收。
- 截图改用已有 GLX 适配；本轮未修改 GPU 扩展或系统驱动。
- `f1-acceptance`：20/20 布局、9/9 到位、6/6 近限位通过；刹停加速度约 2.07 m/s²，整体失败。原因是从实测位置重启参考导致伺服指令回跳。
- 修正 C2 连续参考交接后的定点检查：刹停峰值加速度约 0.091 m/s²，低于 X/Y 0.30、Z 0.20 m/s² 门槛。
- `f1-acceptance-v2` 通过原检查，但追加物体速度检查发现干扰物仍有数值抖动；不将“没掉桌”表述为完全静止。
- 种子 9 单变量诊断：延长落稳时间、noslip=0、干扰物降低扭转摩擦均未达到追加速度门槛；0.5 ms 步长下五个物体通过。未保留 noslip 和摩擦改动。
- v3 扩展到20布局后附加低速度诊断为11/20，不是全部通过；九点/限位/制动仍通过。0.5 ms + noslip=0 的种子2对照也未消除罐体抖动，因此没有采用该改动。
- 最终按语义分开 `supported` 和 `low_velocity`：F1 原要求是支撑、穿透和平台运动；额外低速度指标独立报告，不能说成完全静止。没有变更平台阈值、杯子摩擦或关闭物体自由度。
- 补齐前臂安装梁与 Z 滑杆的可视/碰撞几何；隐藏 group 2 的 YCB 碰撞网格只影响显示，物理碰撞不关闭。
