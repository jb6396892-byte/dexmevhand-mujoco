## 答辩叙事骨架

1. 真实视频标签不是机器人动作，需要重定向与自由物体动力学验收。
2. v9 通过联合动作优化获得无名指承力，而不是强行设置杯子位姿。
3. 当前研究问题：第二视频的单场景成功能否转化为双抓法的学习控制。
4. 开发与留出严格分开，同时保存固定动作、直接 BC、残差 BC 的成功和失败。
5. 最终只按真实闭环结果下结论；不把合成工况当成新的真实视频。
