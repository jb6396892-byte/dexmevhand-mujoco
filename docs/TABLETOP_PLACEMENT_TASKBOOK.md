# 抓杯搬运与桌面放置任务书

日期：2026-10-08。状态：P1-P5 本轮工程验收完成；20 个新场景完整成功 **16/20（80%）**，300 项软件回归与 Qt 检查通过，未启动训练。四个失败保留，不声称任意布局必然成功。[结果、截图与答辩资料](presentation/placement_return/README.md) · [开发日志](run_logs/2026-10-08-tabletop-placement.md)。

## 1. 目标与范围

在现有“导航 → 抓取 → 抬杯 → 搬运”之后增加“下降 → 桌面承重 → 松手 → 撤离 → 稳定确认”，完成完整抓取放置任务。沿用自由基座 Adroit、025_mug（缩放 0.8）、已知初始位姿、现有两视频局部策略和 Qt，不新增机械臂、物体模型或感知任务。

**用户最新确认**：杯子放在 Qt 指定目标 XY 的桌面上，杯口朝上；手撤至无碰撞的安全悬停点，确认杯子站稳后再避障返回任务开始记录的手中心。杯子不返回原位。

保留“搬运并保持”原模式及旧权重，新增“搬运并放下”模式。第一版用规则状态机、现有规划器和接触反馈实现，不默认训练新模型。需要新的腕部姿态控制或纠偏训练时，先输出失败证据和范围评估。

## 2. 现有基础与必须改变的地方

基线 `428aa85`：整桌搬运工程验收 18/20；这不是放置成功率。控制核心为 `whole_table/task.py`、`loaded_motion.py`，Qt 为 `desktop/navigation_window.py`，原入口 `scripts/191_launch_navigation_qt.sh`。

- `NavigationTask.run()` 当前只接收 reach/grasp/lift/transport；候选必须扩展为完整放置预演，不能搬运可行就默认能放下。
- `LoadedMotion` 当前把杯子计入载荷包络，要求持续三指对握，且固定手指控制。释放时需要独立阶段控制，不能直接关闭全部安全检查。
- 现有携物前馈施加在手执行器上。桌面承重时应平滑卸载，避免仍按全杯重量补偿而提起杯子或压住桌面。
- `carry()` 结束会恢复执行器参数和量程。新增放置必须连续交接，保留实际状态和控制目标，不能重置、跳变或沿用失效的局部量程。
- 现有导航主要是固定姿态平移。先测两种抓法搬运结束后的杯子倾角；若不能满足直立落杯，不得靠放松倾角验收掩盖，应先补有限腕部纠姿及其碰撞验证。
- 现有语言技能表没有 place，不能仅让 Qt 接受“放下”而后端仍只执行 transport。

## 3. 坐标与交互约定

放置模式的目标 XY 表示杯子模型原点在世界坐标中的水平位置，单位内部为米、Qt 为毫米。旧模式目标 XYZ 含义保持不变。

放置模式不让用户把目标 Z 填成 0。桌面高度从实际支撑碰撞几何计算；给定计划杯姿态 R 和局部碰撞表面顶点 v，接触原点高度按 `z_origin = z_table - min((R @ v).z)` 计算，再由低速接触控制完成落桌，而不是写入物体位姿。杯轴从模型标定，不能未经验证就假定模型局部 Z 轴指向杯口。

目标合法性同时检查：杯底支撑区域在桌内、杯子 footprint 不与杂物重叠、手杯下降扫掠空间、张手扫掠空间、空手撤离通道。用户指定位置不合法时解释原因，不悄悄改到旁边；随机验收的几何合法但规划失败场景仍计失败。

Qt 新增模式、落点 XY、下降速度、释放时长和撤离距离；高度自动计算并只读显示。调参范围先经开发验证再开放。遥测增加杯底间隙、倾角、杯桌承重、手杯接触力、杯子速度、放置阶段和失败原因。执行途中不修改参数。

## 4. 执行状态机

| 子阶段 | 控制工作 | 进入下一阶段的条件 |
| --- | --- | --- |
| preplace 放置前检查 | 保持当前抓法，检查落点、下降和撤离空间；移动至落点上方 | 抓稳、到位、低速，倾角满足落杯要求 |
| lower 低速下降 | 保持 XY 和手型，沿已检查路径下降；临近桌面减速 | 杯底到桌面且杯桌接触持续，不能只按时间触发 |
| settle 载荷交接 | 停止继续下压，平滑减少手的载荷前馈；继续支撑杯子 | 桌面出现稳定向上承重，杯子低速，无过量穿透 |
| release 渐进松手 | 两种抓法各自验证张手轨迹；逐渐减小夹持，不直接倒放原动作 | 桌面持续支撑，手杯承力降到阈值以下，杯子无明显滑动或倾倒 |
| retreat 空手撤离 | 使用张开后手型重新计算包络；把杯子重新视为障碍 | 手与杯分离，沿合法路径到安全悬停点 |
| verify 稳定确认 | 手不再支撑杯子，继续物理积分并观测 | 杯子独立站稳，位置、速度、倾角和接触均达标 |
| return_home 返回起点 | 按放置后的杯子和杂物位置重算空手路径 | 手中心距记录起点不超过 3 mm，低速保持 1 s；杯子仍站稳 |

接触规则按阶段切换：下降/放置允许指定的“杯子－桌面支撑面”接触，但穿透仍受限；始终禁止手撞桌、手/杯撞其他物体。释放期间逐步放弃对握条件，替换成桌面支撑条件；撤离后必须无手杯接触。不能通过删除碰撞几何或禁用碰撞来实现松手。

按实际仿真时间设置超时，记录每次切换条件。承重不足禁止松手；松手前失败可在已验证抓稳且返程无碰撞时上撤，否则停止。松手后异常不盲目重新夹紧。Qt 停止应取消控制并暂停仿真，保留现场，不把关闭窗口或暂停当成站稳成功。

## 6. 拟定验收标准

以下为开发起始标准，在开发结束后冻结；是本项目工程门槛，不是论文或硬件安全标准。

| 指标 | 起始验收值 |
| --- | --- |
| 完整任务 | 导航、抓稳、抬杯、搬运、落桌、松手、撤离和返回记录的手中心全部完成 |
| 最终 XY 误差 | 不超过 20 mm |
| 杯口朝上 | 标定杯轴相对世界竖直倾角不超过 10 度 |
| 杯底落桌 | 与支撑平面间隙绝对值不超过 2 mm，同时存在杯桌接触 |
| 独立稳定 | 撤手后连续 2 s 内，杯子线速度不超过 10 mm/s、角速度不超过 0.1 rad/s、XY 漂移不超过 5 mm |
| 桌面承重 | 最终窗口至少 95% 采样有杯桌支撑，平均向上接触力在杯子重量的 0.8–1.2 倍；与低速条件联合判定 |
| 完全释放 | 最终窗口无手杯接触；空手与杯/其他物体保持已验证的安全间隙 |
| 碰撞与穿透 | 沿用 1 mm 穿透上限和现有工程运动限值；无非法接触；杯桌必要接触单独审计 |
| 控制真实性 | 实际执行期间杯位姿写入为 0、物体辅助力为 0、无重置补救；仅执行器控制与物理积分 |
| 成功率 | 新 20 场景至少 16 个完整成功；另报两抓法选用数、阶段失败、条件放置成功率及耗时 |

稳定窗口按物理子步统计，不以 Qt 低频画面代替。杯桌法向力需按接触坐标转换到世界系后聚合，不能把力模长或手指夹持力当成桌面承重。瞬时接触丢失采用持续时间判据，不能只靠一个接触帧松手。

专项用例至少覆盖：落点占用、桌外目标、下降时手指碰桌风险、张手受阻、杯子支撑不足、倾斜杯、用户停止。安全拒绝在专项测试中可以通过，但在完整随机任务中不能算放置成功。两个抓法的开发测试单列；自动选用后的总体 80% 不代表每种抓法都达到 80%。

## 7. 语言计划与性能

新增高层 `place` 目标，内部展开 lower/settle/release/retreat/verify，不要求语言模型直接输出执行器动作。“搬到目标位置”保持原有悬停语义；“把杯子放到目标位置的桌面上”才进入完整放置。“放回原位”如实现，显式使用任务开始记录的 XY，不与目标点混用。

原 LoRA 未验证新技能，先通过明确的规则解析、技能白名单和前置条件形成可审计计划；界面标明规则路径，不能宣称已训练出放置语言能力。未知或模糊指令不降级成直接松手。是否继续训练 LoRA 由实际指令评估决定。

放置会增加预演成本。先做落点/下降/张手/撤离的廉价几何筛选，再对剩余候选运行完整物理验证；一旦承重或抓握失败立即终止候选。复用环境和不变几何，不在本任务同时改写整套并行规划。分别记录几何搜索、物理预演、实际执行耗时，不以删减安全检查换取提速。

## 10. 实施时固定的范围

- 默认释放时长 5 s、临桌下降速度 0.5 mm/s、水平撤离分量 60 mm、上升 120 mm；仅手中心返回初始位置，不恢复原始手指和腕部角度。
- 独立验收随机落点预先排除杯体越桌及释放工作区受阻，杯子投影包络与其他物体投影包络留 120 mm 轴向间隔。该值是保守的目标准入规则，不是物理碰撞阈值，也不能保证任意手型的下降路径可行；后续仍做完整物理预演。手动落点不满足时直接拒绝，不自动移动目标。
- 仍使用原 1 mm 穿透与各平移轴 0.5 m/s² 工程加速度门槛；保留全部合法布局中的失败。实际接触力来自仿真，不是真实视频力标签。
