## 答辩常见问题

- **已经训练语言模型了吗？** 没有，用户本轮选择先搭框架；不能展示虚构的 LoRA loss 或语言准确率。
- **为什么 JSON 合法还要看语义？** 搬运计划可以合法，但用户只要求拿起，仍是理解错误。
- **为什么叫可行性分数而不是成功率？** 它由标准场景穿透余量计算，只有少量已有回放证据，没有概率校准。
- **和真实视频是什么关系？** 底层专家动作来自视频手姿与杯姿，经重定向及物理优化；高层语言是额外的任务接口，不是凭语言重新生成杯子轨迹。
- **下一步先修共享盘吗？** 不需要。本轮确认宿主机 shared 为 rw，初始 ro 是沙箱视图；下一步是获得安装/训练确认后使用正确权限执行隔离环境准备。
